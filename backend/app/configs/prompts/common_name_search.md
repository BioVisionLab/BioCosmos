---
title: Common Name Search
name: search_by_common_name
---

Find species by their stored common names. Pass the common-name phrase from
the user's request unchanged; the database resolves it. Never translate a
common name into a scientific name or invent a reference taxon.

Use for direct name requests such as "monarch" or "glasswing butterfly".
Combine with location, traits, or appearance tools for additional constraints.
Do not use this filter for the reference in a similarity request: pass that
name to search_by_image_similarity instead.
